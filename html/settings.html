College Demo Quick Notes

Key points for demonstration

1. Pure Frontend Stack: Built using semantic HTML5, modern CSS3 with CSS variables, Vanilla JavaScript, Chart.js, and LocalStorage.

2. Live Stock Thresholds: Real-time color badges (Green for healthy, Orange for low stock, Red for stockouts).

3. Negative Stock Protection: Outward adjustments prevent stock from dropping below zero.

4. Audit Trail: Every adjustment logs timestamp, quantity change, and reason in LocalStorage.
